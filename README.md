# -Birch
🌿 Birch - це власна мова програмування, створена для простого та зрозумілого написання коду.  Birch має власний синтаксис, файли з розширенням .birch та підтримує змінні, виведення тексту, умови if/else, порівняння та відступи.  Мета Birch - створити просту, зрозумілу та гнучку мову програмування, яку легко вивчати й розширювати.
