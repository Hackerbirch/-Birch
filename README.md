# -Birch
🌿 Birch - це власна мова програмування, створена для простого та зрозумілого написання коду.  Birch має власний синтаксис, файли з розширенням .birch та підтримує змінні, виведення тексту, умови if/else, порівняння та відступи.  Мета Birch - створити просту, зрозумілу та гнучку мову програмування, яку легко вивчати й розширювати. 

# ?? Birch

Birch — власна проста та зрозуміла мова програмування з власним синтаксисом і файлами `.birch`.

## ?? Як запустити Birch

### 1. Створення програми

Створіть файл із розширенням:

program.birch`

Наприклад:

birch

birch set name = "Maks"
birch say name
2. Запуск
Якщо Birch встановлено на комп'ютері, файл .birch можна запустити подвійним кліком.
Також можна запустити через командний рядок:
birch.bat program.birch
?? Основні команди
Виведення
birch say "Hello, Birch!"
Змінні
birch set name = "Maks"
birch say name
Умови
birch set age = 12

birch if age >= 12
    birch say "You can!"
birch else
    birch say "Too young!"
?? Розширення файлів
Програми Birch використовують розширення:
.birch
